Catch SQL mistakes before they reach your database.

sqlsift checks queries against your schema files for unknown tables and columns, typos and type mismatches, with no database connection. This playground runs entirely in your browser via WebAssembly; your SQL never leaves the page.

    Use it in your project

    The same checks run from the command line, in CI, and in your editor. Point sqlsift at your schema (migrations, schema.sql, a pg_dump…) and the queries you want to validate.

    Run it once

    No install needed with npx.

    npx sqlsift-cli check --schema schema.sql query.sql

    Install

    From npm or crates.io.

    npm install -g sqlsift-cli
# or
cargo install sqlsift-cli

sqlsift check -s schema.sql queries/*.sql

    GitHub Actions

    Fail pull requests that reference columns that do not exist. Add -f sarif to upload results to Code Scanning.

    # .github/workflows/sqlsift.yml
name: SQL Lint
on: [push, pull_request]
jobs:
  sqlsift:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npx sqlsift-cli check --schema schema.sql queries/*.sql

    Configure defaults with a sqlsift.toml, silence a line with -- sqlsift:disable E0002, or get live diagnostics in VS Code. See the README.
